# 每日财经新闻看板 v1.0.1

把今日财经新闻一键变成**可点击聚合过滤的离线看板**。

![预览](https://img.shields.io/badge/python-3.8%2B-blue) ![依赖](https://img.shields.io/badge/依赖-零第三方-green) ![产物](https://img.shields.io/badge/产物-自包含HTML-orange)

## 三步上手

```bash
cd daily-finance-dashboard

# 1. 单次刷新（生成 每日财经新闻_板块分类.html）
python3 scripts/refresh_daily_news.py

# 2. 常驻模式：每 10 分钟自动抓取刷新
python3 scripts/refresh_daily_news.py --loop 600

# 3. 打开生成的 HTML，双击即可（也可放内网静态服务器）
```

## 看板长什么样

- **顶部 KPI 卡**：今日新闻 / 🔴利好 / 🟢利空 / ⚪中性 / 📂板块 / 🏷️个股 —— **全部可点击过滤**，再点取消，可叠加组合（如「利空 × 电力能源」）
- **吸顶板块菜单**：15 类行业板块 chip，点击聚合该板块新闻
- **新闻行**：时间 + 情绪圆点 + 标题 + 板块标签 + 个股标签；**点击弹出详情**（摘要、判定依据关键词、原文链接）
- **右上角倒计时**：10:00 归零自动载入脚本重抓的新数据

## 特性

- ✅ 零第三方依赖：仅 Python 标准库，产物零 CDN 自包含 HTML，断网可用
- ✅ 数据源公开稳定：东方财富资讯列表 API（宏观政策 345 + 财经要闻 344），单栏目失败优雅降级
- ✅ 三维分类：情绪（关键词权重打分）+ 行业板块（15 类词典）+ 个股（60 只词典 + 6 位代码）
- ✅ 词典全开放：改脚本顶部 `POS_KW/SECTORS/STOCKS` 等常量即可扩展，无需动逻辑
- ✅ 自动刷新闭环：`--loop 600` 常驻 + 页面倒计时 reload，10 分钟数据保鲜

## 适用场景

- 个人每日盘前/盘后资讯速览
- 团队内网资讯看板（HTML 可直接静态托管）
- 交付归档：配合 `manifest.json`（sha256 清单）可校验分发一致性
